# ⚡ Customer Churn Intelligence Portal

A professional machine learning web application built with **Streamlit** to analyze subscriber behavior and predict customer churn in the telecommunications industry in real time.

## 🚀 Features
- **Interactive Home Dashboard**: Highlights project metrics and dataset previews.
- **Real-Time Prediction Engine**: Evaluates customer details (tenure, charges, contract type, etc.) to assess attrition risk instantly.
- **Exploratory Data Analysis (EDA) Dashboard**: Visualizes key trends, distributions, and behavioral patterns using Seaborn and Matplotlib.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Machine Learning**: Scikit-Learn (Random Forest)
- **Data Manipulation**: Pandas, NumPy
- **Data Visualization**: Matplotlib, Seaborn

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```
   git clone [https://github.com/SnehalPal43/telecom-churn-prediction.git](https://github.com/SnehalPal43/telecom-churn-prediction.git)
   cd telecom-churn-prediction
   ```
## Install dependencies:

pip install streamlit pandas numpy scikit-learn matplotlib seaborn

## Run the Streamlit app:

streamlit run app.py
